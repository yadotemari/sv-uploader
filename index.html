館内360アップローダー

0初期設定（最初の1回だけ）

Google Cloudで作成したクライアントIDを貼り付けて保存してください。この端末のブラウザに保存されます。

★お宿さまを選ぶ

お宿さまを登録・編集する
地図の位置は、館内タブの地図に宿が写っている状態で登録すると、その位置と拡大の具合が保存されます。プレイスIDはプレイスIDファインダーで調べます。
登録内容はこのパソコンのブラウザに保存されます。別のパソコンでは登録し直してください。
撮影チェックリスト（基本の10か所）
選んでいるお宿さまごとに保存されます。場所の名前は書き換えられます（例：「客室・窓際／縁側」→「客室・露天風呂」）。女湯は撮影しません。
共有リンク・QRコード
お宿さまへの報告や、館内掲示・チラシ・ホームページ用です。QRコードは画像として保存できます。

1道中の360度写真をまとめて選ぶ

宿へ向かう道で、5〜10mおきに撮った写真をまとめて選びます（動画から切り出した写真でもOK）。ファイル名の順（＝撮影順）に並びます。位置情報が入っている写真は、自動で地図に置かれます。

2地図で順番に置く

写真を選ぶと、ここに「次に置く写真」が出ます。
道に沿って、撮影した順に地図をクリックしていきます。番号付きの丸はドラッグで微調整できます。
カメラのレンズ正面を進む方向に向けて撮っていれば、補正は0のままでOKです。後ろ向きに持っていた場合は180にします。

3まとめて公開

道路の写真は宿そのものではないので、プレイスID（宿とのひもづけ）は付けずに公開します。撮影日時はファイル名から自動で入ります。
足元を見たときの見え方
公開直後はGoogle側の処理が終わっておらず、つなぐのに失敗することがあります。その場合は、数時間〜1日おいてから「写真同士をつなぎ直す」を押してください（前回まとめて上げた写真が対象です）。

1館内の360度写真をまとめて選ぶ

1部屋・1フロア分など、まとめて選べます。ファイル名の順（＝撮影順）に並びます。下の写真をクリックすると、その写真を選べます（黄色の枠）。

21枚ずつ、位置・向き・場所名を決める

写真を選ぶと、ここに「今選んでいる写真」が出ます。
地図をクリックすると、黄色の写真がそこに置かれ、次の写真に進みます。番号の丸はドラッグで動かせます。三角が向き（写真の正面の方角）です。
見取り図を地図に重ねる
正面がわからない写真は、公開後に④の「修正」→「写真の目印で向きを合わせる」で直せます。
ぼかし（写り込んだ人・車のナンバーなど）
下の写真で、ぼかしたい所をクリックするとぼかしが付きます。付けたぼかしをもう一度クリックすると消えます。公開するときに写真へ焼き込まれます。

3まとめて宿とひもづけて公開

宿名は「★お宿さまを選ぶ」で選んだ宿名が入ります。右は今選んでいる写真のラベルです。
足元を見たときの見え方
公開直後はつなげないことがあります。そのときは公開後に④の「チェックした順番につなぐ」でつなぎます。

1360度写真を選ぶ

Insta360アプリで「360度写真」として書き出した横長（2:1）のJPGを選んでください。
ぼかし（写り込んだ人・車のナンバーなど）
下の写真で、ぼかしたい所をクリックするとぼかしが付きます。付けたぼかしをもう一度クリックすると消えます。公開するときに写真へ焼き込まれます。

2位置と向きを決める

地図をタップすると撮影位置に矢印が立ち、自動で拡大します。さらに「＋」で拡大し、矢印をドラッグして部屋の中の位置まで合わせられます（拡大すると写真はぼやけますが、位置は正確に指定できます）。左下の目盛りで距離の目安がわかります。
Googleマップ（パソコン）で航空写真にし、撮った場所を右クリック → 一番上の数字を押すとコピーされます。それをここに貼ると、Googleの航空写真とぴったり同じ位置になります（このツールの航空写真はGoogleと数メートルずれることがあります）。
0=北 / 90=東 / 180=南 / 270=西。Insta360で撮った時にレンズ正面が向いていた方角です。
写真の目印で向きを合わせる
写真の上の「北・東・南・西」の文字が、今の向きの設定で写真のどの方向にあたるかを示しています。地図と見比べて合っていれば完了です。
見取り図を地図に重ねる（館内の位置合わせが楽になります）

3宿とひもづけて公開

プレイスIDファインダーで宿名を検索してコピーしてください。宿ごとに保存されます。
ひもづけは公開後に④の「Googleに登録されている内容」から、写真を消さずに付けたり外したりできます。
英語は「場所」から自動で入ります。違うときや空欄のときは書き換えてください。
写真の真下（足元・三脚が写る部分）に、白い丸のラベルとして入ります。Googleのルール（文字は写真の上か下の一方だけ）に沿った入れ方です。
足元を見たときの見え方

4投稿済みの写真

公開まで数時間〜数日かかることがあります。Google側で位置や向きが補正される場合があります。
「修正」を押すと、位置・向き・階数を直せます。撮影日時も直したいときは、修正中に①で元の写真を選び直すと、正しい日時で差し替えます。
写真同士をつなぐ（館内の写真を建物の中に並べて見せる）
つながった写真は、写真の中の矢印で行き来できます。おすすめは「順番につなぐ」：歩いて移動する順（例：玄関 → 廊下 → 客室入口 → 客室中心 → 窓際）にチェックを入れて押すと、その順番どおりに1本道でつながります。チェックの横に出る番号が順番です。
分かれ道（廊下から別の部屋へ など）は、分かれ目の写真から別の部屋までを、もう一度「順番につなぐ」で足します。壁の向こうへ矢印が出るなど変なつながりは、「つながりを外す」でいったん外してからつなぎ直します。
チェックした写真の位置をまとめてずらす
Googleマップで青い点が建物の外など、少しずれて見えるときに使います。1枚を「修正」でGoogleの座標に合わせると、動かした距離がここに自動で入るので、残りの写真にも同じだけ当てはめられます。向き・つながり・ひもづけは変わりません。

5閲覧数レポート

④の一覧を読み込むたびに、その日の閲覧数を記録します。前回の記録や約1か月前の記録と比べて、どれだけ見られたかがわかります。Googleの閲覧数は反映が遅れることがあります。
